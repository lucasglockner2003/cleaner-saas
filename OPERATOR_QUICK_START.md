# OPERATOR_QUICK_START

Fast operator guide for first pilot usage.

## 1. Login

1. Open the app URL.
2. Sign in with:
   - `owner@cleanerops.local / owner123` or `ops@cleanerops.local / ops12345`

## 2. Prepare pilot data

1. Go to **Pilot Tools**.
2. Run **Demo mode helper** (recommended) once.
3. Wait for all steps to show success.

## 3. Daily operations flow

1. **Schedule**
   - Review day/team board
   - Check risk/load badges
   - Reorder or assign if needed
2. **Visits**
   - Open visit row
   - Click **Start house**
   - Add notes/proof placeholders
   - Click **Finish house**
3. **Monetization**
   - Review invoice statuses
   - Review payment statuses
4. **Communications**
   - Check reminder/completion/invoice jobs
   - Retry failed jobs

## 4. If something is missing

1. Return to **Pilot Tools**.
2. Re-run the sequence:
   - Import CSV
   - Generate schedule
   - Generate fake visits
   - Generate invoices
   - Simulate payments

## 5. What “good” looks like

- Schedule board populated with weekday visits
- Visits can be started and finished without errors
- Completed visits show history metrics
- Invoices and payments are visible and linked
- Failed jobs are visible and retryable
